# AI Incident Database (`data/clean/aiid.jsonl`)

**What / feeds:** community catalogue of AI harm incidents; feeds the warning-signs incident trend.

- **Source:** weekly snapshot linked from `https://incidentdatabase.ai/research/snapshots/` (GraphQL API is origin-restricted). Snapshot used: `backup-20261019101022`, fetched 24 Oct 2026. OECD AI Incidents Monitor has no export/API (HTML only); not used.
- **Re-run:** `node doomclock/pipeline/fetch/aiid.ts` (extract; works offline), then `node doomclock/pipeline/fetch/clean.ts aiid`. `aiid.ts` uses the newest local `data/raw/aiid/backup-*.tar.bz2` and does not touch the network; it fetches the snapshots page and the latest snapshot only when no local snapshot exists. To move to a newer snapshot, download it into `data/raw/aiid/` first. Raw: `data/raw/aiid/backup-20261019101022.tar.bz2` (115 MB). The extracted dump is deleted after cleaning; `aiid.ts` re-extracts it.
- **Record:** `ts, first_report_ts, source:"aiid", kind:"incident", id` (incident_id)`, url` (incidentdatabase.ai/cite/<id>)`, event_date` (when it happened)`, title, description` (≤400 chars)`, deployers[], developers[], harmed[], n_reports, first_report_url`.
- **`ts`:** `max(first_report_ts, event_date + "T00:00:00Z")`, i.e. when the incident was first public, but never before it happened. **Not** the AIID submission date (later).
- **`first_report_ts`:** the earliest `date_published` of the incident's linked reports. For 31 of the 821 incidents it is before `event_date` (AIID links some reports dated before the event they are filed under), so `ts` moves forward to `event_date`: by 1–8 days for 18 of them, 22–138 days for 12, and 322 days for one. Every record has it; it equals `ts` for the other 790.
- **Filters:** `first_report_ts` ≥ 2024-10-24 (3 incidents first reported earlier but with an `event_date` after it stay out) and `ts` ≤ now; incidents with no dated report dropped (report dates in an odd `$numberLong` form are ignored). Reports and classification tables are not kept.
- **Counts:** 821 records, 2024-10-24 → 2026-10-11; 0.9 MB. Per month by `ts`: 2024-10 11, 11 13, 12 24; 2025: 29, 43, 38, 46, 33, 33, 40, 41, 21, 39, 28, 49; 2026: 41, 36, 35, 32, 33, 29, 58, 27, 31, Oct (to the 11th) 11.
- **Quirks:** recent months are undercounted (incidents are added weeks after the report). The snapshot is today's state: an incident that was added to AIID late still gets its early `ts`, which is correct for "public" but means the backtest sees it only because of hindsight about AIID inclusion. Treat the last ~month as incomplete.
