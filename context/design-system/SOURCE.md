# Source

This folder is a copy of the `project/` folder of the Doom Clock design system artifact:
https://claude.ai/artifact/VGsoVrzhbyFcnM1otCMgJN (version 1792874841-3f72, copied 24 Oct 2026).
The artifact is the source of truth. When it changes, replace this folder with its `project/` files
again and re-run `node .lavish/prototype/gen-tokens.mjs`.

The `components/*/preview.html` files expect the CSS the artifact page generates from `tokens.json`,
so they only render properly on the artifact.
