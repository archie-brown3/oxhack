Square buttons and caps tabs, as the Bulletin's. Use at most one oxblood primary per view.

- **Variants:** `dc-btn--primary` (oxblood fill) for the one thing the view is for, such as "End turn" or "Play from today". `dc-btn--outline` (an `action` border) is for strong secondary actions like "Roll another" or "View full statement". The default has a `rule-strong` border. `dc-btn--quiet` has no border.
- Write labels verb-first in sentence case. Show the key in `kbd` (R, E, ⏎).
- **Tabs:** `dc-tabs` with `aria-pressed` makes caps chapter tabs. The active one is `ink` with an `action` underline.
