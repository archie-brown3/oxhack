The three provenance labels, REAL, SIMULATED and GAME RULE, plus the mock mark for invented numbers.

- **Classes:** `dc-label--real` (solid dot, `ink`), `dc-label--sim` (hollow ring, italic, `sim`) and `dc-label--rule` (open square, `ink-3`). Use `dc-mock` straight after a number.
- Use them beside any number or claim whose source isn't obvious. They read on both themes.
- **Don't:** invent a fourth label, or use the label style for anything else.
